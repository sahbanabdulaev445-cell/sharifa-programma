# Sharifa — обращение к родителям

https://sahbanabdulaev445-cell.github.io/sharifa-programma/

Только обращение пользователя из 12 абзацев, без дополнительных сведений. Текст и новые иллюстрации объединены в десяти изображениях. Оформление выполнено по предоставленным визуальным образцам: синий, золото, архитектурные арки, зелень и тёплый свет.

Текст программы, цитаты и сведения с прежних постеров удалены из текущего сайта. Приложенные изображения использованы только как образцы оформления.

Статический HTML, CSS и JS. Прокрутка, стрелки, увеличение и печать. Все основные изображения доступны без JavaScript. `/letter-preview/` перенаправляет на актуальную страницу.
